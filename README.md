🌟 Features
RAG Architecture: Leverages LangChain for context injection and precise retrieval.

Vector Database: Uses FAISS for efficient document embedding and similarity search.

LLM Integration: Powered by OpenAI models for highly accurate, context-aware responses.

Interactive Frontend: A responsive, real-time React chat interface.

🛠️ Technical Stack
Backend: Python, Flask, LangChain, OpenAI API, FAISS.

Frontend: React, Vite, Vanilla JavaScript (ES6+), CSS3.

🚀 Architecture Overview
The system consists of a Flask-based Python API that processes user queries, retrieves relevant context from a vector store, and generates answers using an LLM. The frontend is a modern React SPA that handles real-time state management and communicates with the backend via RESTful endpoints.
